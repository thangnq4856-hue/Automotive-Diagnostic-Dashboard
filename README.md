# Automotive HiL Diagnostic & Telemetry Dashboard

An interactive real-time ECU telemetry visualization and diagnostic dashboard built with Python, Tkinter, and Matplotlib. 

## Key Features
- **Real-time Telemetry Plotting**: Dynamic display of vehicle speed (km/h) and engine RPM.
- **Fault Detection Simulation**: Integrated DTC (Diagnostic Trouble Code) detection logic based on Automotive UDS (ISO 14229) principles.
- **Interactive Control**: Toggle ECU fault states and clear fault codes directly from the HMI.

## Tech Stack
- **Language**: Python 3.x
- **GUI Framework**: Tkinter
- **Data Visualization**: Matplotlib (Embedded in Tkinter Canvas)
